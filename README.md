# Adriaan-Cloet.github.io

The root of https://adriaan-cloet.github.io/. It exists so the domain can be verified in Google
Search Console (the verification tag goes in `index.html`), which Google's consent screen for
SimpleCalendar needs. SimpleCalendar's own pages are published from
[Adriaan-Cloet/SimpleCalendar](https://github.com/Adriaan-Cloet/SimpleCalendar) (`site/`).
